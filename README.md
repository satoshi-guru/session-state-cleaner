# session-state-cleaner

Strips ungraceful-exit noise from `SESSION_STATE.md` files generated by Claude Code projects.

## The problem

Claude Code appends an `## ⚠️ Ungraceful exit` block to `SESSION_STATE.md` every time a session ends without running `/session-close`. Over time these pile up and bury the actual session history in noise.

```
## ⚠️ Ungraceful exit — 2026-05-22 09:05 (hook)
Branch: game-backend | Last commit: 0d8c550
session-close did not run. Run /session-close at the start of next session to catch up.

## ⚠️ Ungraceful exit — 2026-05-22 09:37 (hook)
...
```

## The fix

```bash
python3 clean_session_state.py path/to/SESSION_STATE.md
```

Removes all `## ⚠️ Ungraceful exit` blocks in place, preserving everything else — phase state, architecture invariants, bug notes, and proper `## Session NNN` entries.

## Usage

```bash
# Default: SESSION_STATE.md in current directory
python3 clean_session_state.py

# Explicit path
python3 clean_session_state.py /path/to/your/project/SESSION_STATE.md
```

No dependencies — pure Python 3 stdlib.

## What it keeps

- All structured sections: current phase, test count, active plans, invariants, decisions, bugs
- Proper session entries (`## Session NNN — date | Branch: ...`)

## What it removes

- Every `## ⚠️ Ungraceful exit` block and its contents
